# CLAUDE.md

Preferences for Claude Code when organizing this Downloads folder.

## Scope

These rules apply only to `~/Downloads`. Do not apply this organization scheme to other folders unless explicitly asked.

## Organization scheme

- Sort files into subfolders by **month-created**, using the format `MM-YYYY` (e.g. `01-2026`, `02-2026`).
- Use each file's **date created** (filesystem creation timestamp) to decide which folder it belongs in — not date modified or date downloaded.
- No file-type or project subcategories — month-year is the only grouping.

## Renaming

- Never rename files. Move them as-is, keeping the original filename.

## Duplicates

- When duplicate files are found (same content, e.g. `report(1).pdf` vs `report.pdf`), do not silently delete them.
- Move duplicates into a `Duplicates/` subfolder (at the top level of `~/Downloads`, not nested inside a month folder) so they can be reviewed and deleted manually later.

## Off-limits

- Nothing is off-limits — all files in `~/Downloads` can be organized under this scheme.

## Approval

- Always show the full plan (which files go where, including any duplicates found) before moving anything.
- Wait for explicit approval before executing any moves. Do not batch-execute without confirmation, even within a single session.
